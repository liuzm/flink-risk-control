# RiskFlow 产品 PRD 章节目录

本目录是 RiskFlow 实时风控 SaaS 平台 PRD v1.3 的章节化版本。每个一级章节独立维护，适合产品评审、研发设计、测试验收和运营讨论。

原始完整稿保留在 [PRODUCT_PRD.md](../PRODUCT_PRD.md)，用于全文检索和兼容已有链接；后续内容变更应优先维护本目录中的章节文件。

## 维护规则

1. 一级章节新增内容写入对应章节文件，避免继续扩展完整稿。
2. 功能编号、验收编号和数据对象名称保持全局唯一。
3. 调整产品范围时同步更新第 3、8、12、13 章。
4. 调整租户、权限或资源模型时同步检查第 4、6、10、11、12 章。
5. 每次正式评审后更新第 0 章版本记录，并关闭或补充第 15 章待决策项。
